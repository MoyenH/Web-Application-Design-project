# JobFinder: Static HTML/JS Job Search Platform

## 🌟 Project Overview

**JobFinder** is a multi-page web application designed to help users search and explore job listings. The project is built entirely using **vanilla HTML, CSS, and JavaScript**, making it lightweight, fast, and easy to deploy. It simulates a functional job board experience, featuring job listings, company profiles, detailed job views, and a login interface.

This project is excellent for showcasing skills in classic front-end development, DOM manipulation, responsive design, and local state management (via `localStorage`).

## ✨ Key Features

* **Job Search & Filtering:** Users can search jobs by keyword, location, and category directly from the homepage or dedicated job listings page (`jobs.html`).
* **Job Details View:** Dynamic job detail pages (`job-details.html`) render comprehensive information about a specific role, including responsibilities, requirements, and company details.
* **Company Directory:** A dedicated page (`companies.html`) to browse a list of featured hiring companies.
* **User Authentication (Simulated):** A dedicated login page (`login.html`) with form validation and a simulated login process (using `localStorage` for session management).
* **Interactive UI Elements:** Includes features like ripple effects on buttons, sticky headers, and smooth loading animations (`main.js`).
* **Local State Management:** Utilizes `localStorage` to handle persistent features like saving job listings.

## 🛠️ Technology Stack

The application is built using a purely classic front-end stack:

* **HTML5:** Structure for all five distinct pages (`index.html`, `jobs.html`, `job-details.html`, `companies.html`, `login.html`).
* **CSS:** Styling is managed via an external stylesheet (`css/styles.css`, not provided but referenced).
* **Vanilla JavaScript (ES6+):** All functionality, including filtering, search, dynamic content rendering, form validation, and event handling, is written in pure JavaScript (files like `main.js`, `jobs.js`, `login.js`, etc.).
* **Font Awesome:** Used for icons across the entire site.
